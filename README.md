Controle de estoque 

Sistema capaz de controlar a entrada e a sída de pordutos, podendo mostrar ao usuário os produtos cadastrados, pesquisar o produto pelo nome editar o nome do prouto e remover o produto da lista. Ele sana do usuário a necessidade de ter que se preocupar com o controle de estoque de forma manual.


Sobre o projeto

O sistema ajuda a empresas de pequeno porte a fazerem o controle de estoque com qualidade de forma fácil e com performance para o usuário. Resolvi desenvolver esse sistema quando me deparei com microempresas que ainda utilizavam o sistema manuescrito de controle de estoque, o que gerava perca de produtos e uma má gestão do estoque por conta de falhas humanas.
 
Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Pesquisa de produtos pelo nome
- Edição de produtos
- Remoção de produtos

Tecnologias utilizadas 

- Java 26 Puro

Pré requisitos

- JDK compatível com o projeto

Como executar

1º Clone o repositório 
2º Abra o projeto na IDE ou configure o ambiente
3º Execute o projeto principal 

Estrutura do projeto

- Main (Classe Principal)
- Controller - Classe responsável pelo menu de intereção com o usuário
- Model - Classes responsáveis por armazenar os dados do produto
- Repository - Classe responsável por salvar os dados do produto
- Service - Classe responsável por implementar as regras de negócio
